# localclash-luci

localClash 的 OpenWrt 管理界面。

## 第 1 步：下载安装包

1. 从[发布页](https://github.com/qoli/localclash-luci/releases/latest)按路由器的软件包管理器选择 `.ipk` 或 `.apk`。
2. 在 OpenWrt「系统 → 软件包」上传并安装。
3. 打开「服务 → localClash」，填入订阅后点击「开始初始化」。

在概览页点击「复制 Skill + MCP 指令」接入 Agent。
